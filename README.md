# Ayoun Masr School Hub

Build a 3-page school website called "Ayoun Masr" (عيون مصر).

IMPORTANT: I am attaching 3 reference images showing the exact visual design of the 3 pages. Strictly replicate the layout, color scheme (blue and yellow), spacing, typography style, card designs, and overall visual identity shown in these images. Do NOT introduce a different design direction, do NOT change the color palette, and do NOT add any extra pages, sections, or features beyond what is described below and shown in the images.

Page 1 — Homepage (reference image 1):

Replicate exactly: navigation bar with the school logo and a "Login" button, hero section with activity/event photos and the school's vision, an "About the school" section, the principal's welcome message section, an activities/events photo gallery, and a contact/location section with a map, plus a footer.

Page 2 — Student/Parent Dashboard (reference image 2), accessible after login:

Replicate exactly: student profile card (photo, name, age, class), weekly schedule table, attendance/absence summary, summer activities badges (karate/football), upcoming exams list, Term 1 and Term 2 grades, and fees payment status.

Page 3 — Admin Dashboard (reference image 3), accessible after admin login:

Replicate exactly: overview stat cards (total students, total teachers, fees collected %), a donut chart for fees collected vs outstanding, a chart for attendance trends, and a recent activity summary list.

Functionality:

- The "Login" button on the homepage should lead to a login screen with two account types: Student/Parent and Admin.

- Logging in as Student/Parent redirects to Page 2 with demo/sample data.

- Logging in as Admin redirects to Page 3 with demo/sample data (including working charts).

- All data shown should be placeholder/demo content only, since this is a prototype for a business pitch, not a live system with real student data yet.

Do not deviate from the visual style in the reference images. Do not invent a new design language. Do not add pages, sections, or features that are not explicitly described here or shown in the images.
